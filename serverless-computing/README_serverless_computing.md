## AWS Serverless Application Repository

- Allows users to easily find, deploy or even publish their own serverless applications
- Share applications privately within orgs or publicly
- Upload application and a manifest file
- Deeply integrates with AWS lambda
- Publish
  - Make them available for others to find and deploy
  - Define apps with AWS SAM templates
  - Set to private by default
  - Must explicitly share
- Deploy
  - Find and Deploy published applications
