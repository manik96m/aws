## DNS (Amazon Route 53)

- Amazon's DNS service
- Called 53 because DNS operates on port 53
- Human readable name to IP address.
- Helps with traffic routing.
- Can perform health checks as well.
  - and redirect requests accordingly.
- Supports both IPV4 and IPV6

- Record types

  - SOA (Start of Authority) - this is where DNS starts
  - CNAME - Map one domain name to another
  - NS - Name server records(domain name information)
  - A - Domain name to IP address
